# 场景来源与改编说明

## 《圣玛丽医院》

项目原创的框架验证场景，用于测试虚拟时间、后台事件、行动中断、NPC 知识、Director 干预、存档与回放。

## 《科比特宅邸》

- 原作：*The Haunting*
- 原作者：Sandy Petersen
- 出版方：Chaosium Inc.
- 官方入口：<https://www.chaosium.com/cthulhu-quickstart/>
- 官方定位：收录于免费的 *Call of Cthulhu Quick-Start Rules*，作为新玩家和主持人的入门调查模组。

本项目实现保留了委托、城市调查地点、科比特与教堂的历史关系、宅邸空间、空卧室袭击、浮空匕首、地下隐藏墓室和主要结局因果。实现使用 Living Tabletop 独立编写的 CoC 7版 Quick-Start 兼容规则层与状态模型，中文叙事均为重新概述。

没有纳入项目的材料包括：Quick-Start PDF、原文段落、玩家手卡、宅邸地图、插图、角色卡以及《克苏鲁的呼唤》的规则书文字或原始表格。基础机制由代码独立实现，范围见 `docs/COC_RULES.md`。
