# 自动游玩与多路径测试

`living_tabletop.playtest` 是一个完全离线、可重复的测试实验室。它直接使用正式 `GameEngine`、`WorldKernel` 和 `Director`，不会另写一套简化规则，也不会调用 LLM。

## 运行

```powershell
python scripts/self_play.py --scenario all
python scripts/self_play.py --scenario the_haunting_corbitt_house_v1
python scripts/self_play.py --scenario all --output-dir artifacts/playtests
python scripts/rules_playtest.py --output-dir artifacts/playtests
```

退出码为 0 表示所有强制路线和运行时不变量通过；任何错误都会令脚本返回 1。探索型策略未在回合上限内结束时会产生警告，但不会伪装成通过的终局。

## 两类自动玩家

- 策略玩家只从当前合法动作中选择。内置 `investigator`、`social`、`bold`、`explorer` 和 `random` 五种倾向；它们会记录去过的地点、尝试过的动作，并在低生命时沿移动图的最短路径撤向出口。
- 脚本玩家用于可重复地覆盖指定路径。每一步可声明“直到成功”或“尝试一次即可”，因此能正确测试预期中的行动失败和后台事件中断，而不会盲目刷骰。

## 每回合检查

- 内核列出的合法行动必须被引擎接受。
- 接受行动后，世界版本必须恰好增加 1，时间不得倒退。
- Event Log 序号必须连续。
- 公开线索必须与已发现线索完全一致。
- 现场 NPC 必须与玩家所在地点一致。
- 叙事不得包含尚未公开的完整隐藏事实值。
- 活跃游戏必须至少有一个合法行动。
- 连续八个行动没有产生位置、线索、物品、生命、压力、旗标或终局变化时，报告停滞。
- 报告同时统计 SAN 检定与损失、伤害事件，以及出现重伤的运行数。
- 要求终局的脚本必须得到指定结局。

## 当前固定回归范围

《科比特宅邸》覆盖完整研究胜利、带证据撤离、立即撤离、错误安全报告、匕首直闯、徒手强攻，以及五类策略玩家。所有 33 个手写动作都会被至少一条路线执行。

《圣玛丽医院》覆盖救人并阻止仪式、立即撤离、提灯与强拆档案门的替代路径，以及五类策略玩家。所有 26 个手写动作都会被至少一条路线执行。

移动动作由场景图自动生成，不计入“手写动作覆盖率”，但它们仍会在每次运行中接受相同的不变量检查。

## 规则分支矩阵

`rules_playtest.py` 使用正式引擎执行 7 个确定性案例：接受失败、幸运补点、孤注一掷成功、孤注一掷失败、带奖励骰的对抗战、SAN 检定和重伤。它不是只测数学函数；每个案例都经过真实 `GameEngine` 或 `WorldKernel`，并检查等待选择、时间推进、事件记录和最终副作用。
